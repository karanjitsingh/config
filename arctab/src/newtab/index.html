New tab

What a new tab shows and where the cursor goes.

Quick search

The search bar Ctrl+T (or ⌘T with the Karabiner mapping) opens over the page you're on. Press it again for a real new tab.

Peek

Open links in an overlay on the homepage, like Arc. Esc or clicking outside closes it, ⌘O expands it into this tab, and ⌘-click always opens a new tab.

Search shortcuts

In the search box, type a shortcut's key and then Space or Tab. These belong to this homepage and are separate from Chrome's site search.
